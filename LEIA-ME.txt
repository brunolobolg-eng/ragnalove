ARQUIVOS-FONTE DO ROGUARD (ragnalove)
=====================================
Estes arquivos NAO sao necessarios para o jogo rodar. Sao os originais em alta
qualidade, guardados para editar no futuro. O jogo usa as versoes otimizadas que
ficam em public/.

modelos_3d/originais/   Modelos originais (V2Fun e outros), antes do rig/otimizacao.
                        liria_v2fun.glb   -> public/models/liria.glb (arqueira)
                        assassino.glb     -> public/models/assassin_dk.glb
                        eliana_sam.glb    -> public/models/eliana.glb (guerreira)
                        cleria_sam.glb    -> public/models/cleria.glb (maga)
                        zumbiH.glb        -> public/models/zombie.glb
                        orcattack.glb     -> public/models/orc.glb
                        goblin1/goblin2, rato/ratochefe, Sorcerer, Warlock, Assasino
modelos_3d/rigs/        Versoes ja riggadas (esqueleto do jogo) desses modelos.
modelos_3d/nao_usados_no_jogo/
                        assassin.glb (substituido pelo assassin_dk) e orcboss.glb
                        (o Senhor Orc hoje usa o orc.glb).

imagens/folhas_de_sprites/  Folhas com fundo verde. Recorte com:
                        python scripts/process_sprites.py <folha.png> <prefixo> <poses...>
imagens/arte/           icone.png      -> gere os icones com: python scripts/make-icon.py icone.png
                        tela entrada.png (original sem perda; o jogo usa public/tela-entrada.jpg)
                        equips.png, logo_transparente.png, *_frente.png (artes de referencia)
imagens/nao_usadas_no_jogo/  Imagens que estavam em public/ mas o codigo nao usa.

audio_video/            menu.mp3 (versao da raiz) e roguard_menu_loop.mp4
                        (video do menu, hoje nao usado pelo codigo).

Para usar de novo: extraia, copie o arquivo para a pasta do projeto e peca ao Claude
para integrar.

kenney_particle_pack.zip  Kenney Particle Pack original (CC0, www.kenney.nl): PNGs com fundo
                          transparente e preto + amostras Unity. O jogo usa as texturas geradas em
                          public/fx/kenney/ por: python scripts/build_kenney_fx.py "<pasta PNG (Transparent)>"

ADICIONADOS EM 2026-10 (otimizacao: o repositorio principal ficou mais leve)
---------------------------------------------------------------------------
animacao_ual_originais.zip  Universal Animation Library [Standard] (Quaternius, CC0): FBX e GLB
                            originais (UAL1_Standard e _RM). O jogo usa o JSON/clipes gerados a partir
                            dela (src/render/units/model/ualClips.ts). Para gerar de novo, extraia o zip
                            na raiz do projeto (pasta "Universal Animation Library[Standard]").
cartas_folhas_originais.zip Folhas originais das cartas de monstro (cards2..cards5.png) e reliquias1.png.
                            O jogo usa os recortes em public/sprites/cards/. Para recortar de novo, extraia
                            na raiz e use: python scripts/process_sprites.py (ver o cards.json).

modelos_pesados_originais.zip  Originais ANTES da simplificacao (18 a 8 MB cada, 490k triangulos no
                            cultista): cultist.glb, goblin_warlord.glb, assassin_dk.glb, liria.glb.
                            Os arquivos do jogo em public/models/ sao versoes simplificadas (~1,5 a 4 MB).
                            Para refazer: gltf-transform simplify <original> <saida> --ratio 0.02 --error 0.9
